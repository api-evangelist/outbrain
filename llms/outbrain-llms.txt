# Outbrain (Teads)

> Outbrain Inc. (NASDAQ: OB), which closed its acquisition of Teads in early 2025 and now operates publicly as Teads, is one of the largest open-internet advertising platforms — reaching 2 billion+ consumers per month across 50+ markets with 20,000+ direct advertisers and 10,000+ premium media properties. Its developer surface has three distinct halves: the Outbrain Amplify API for programmatic campaign management and performance reporting, the Teads Report API for asynchronous analytics, and a publisher-side integration layer of mobile SDKs, JS widgets and a conversational-AI ad SDK.

Generated by API Evangelist from the artifacts in this repository (github.com/api-evangelist/outbrain).
Outbrain does not publish an llms.txt of its own; /llms.txt returns 404 on developer.outbrain.com and
developers.teads.com. This file is a faithful index of what Outbrain actually publishes.

## What an agent can and cannot do here

- The Amplify API is a real, callable REST API with 77 documented operations — but access is gated:
  Outbrain admits partners through an application at https://www.outbrain.com/partner-api/.
- Authentication is an opaque `OB-TOKEN-V1` header token, valid 30 days, obtained from `GET /login`
  (HTTP Basic, capped at 2 requests per hour per user) or https://my.outbrain.com/create-token.
- There is NO idempotency key on any Outbrain API. Retried writes create duplicates.
- There is NO MCP server. Teads has announced one as "In Development" for 2026 on the AI Chatbot SDK.
- There is NO A2A agent card, no webhooks, no AsyncAPI, no status page and no published SLA.
- Errors are proprietary JSON, not RFC 9457. Amplify returns `{moreInfo, errorMessage}`; the Teads
  Report API returns `{status, msg}` with dotted `REPORTING.ERROR.*` codes.

## APIs

- [Outbrain Amplify API](https://amplifyv01.docs.apiary.io/): Campaign management and performance reporting. Base URL https://api.outbrain.com/amplify/v0.1 — marketers, budgets, campaigns, promoted links, segments, conversion events, geo/interest/IAB targeting and 23 reporting endpoints.
- [Teads Report API](https://teadsapi.docs.apiary.io/): Asynchronous analytics reporting. Base URL https://api.teads.tv/v1/analytics — POST a report, poll it, download CSV/JSON/XLSX. OAuth bearer auth.
- [Outbrain Engage API](https://developer.outbrain.com/apis/): Publisher-side content recommendations. Base URL https://odb.outbrain.com — recommendation retrieval plus impression and click reporting.
- [Teads Advertiser Conversion API](https://github.com/teads/teads-advertiser-conversion-api-gtm-template): Server-to-server conversion events for cookieless measurement. Base URL https://r.teads.tv.
- [Teads In-Chat API v2.0](https://developers.teads.com/docs/Chatbot-AI-SDK/Getting-Started/integration-guide): Contextual sponsored recommendations for chatbot and LLM publishers. Base URL https://mv.outbrain.com/Multivac/api/in-chat-recs. Public beta since 2025-11-12.
