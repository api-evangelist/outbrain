Teads announced its Audience Planning API integration into Havas Media Network's Converged.AI platform, enabling direct system-to-system audience activation within agency workflows. The integration allows planners to define audiences within the platform and push those definitions seamlessly into Teads Ad Manager, reducing manual rebuilds and accelerating activation across mobile, desktop, and connected TV channels. The partnership maintains consistency and privacy-first targeting while streamlining the audience planning process for Havas agency teams.
